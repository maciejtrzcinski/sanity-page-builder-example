# Security Policy

## Supported versions

This is an example/demo project; only the latest `main` is maintained.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report privately via [GitHub's "Report a vulnerability"](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
flow on this repository (Security → Advisories), or email the maintainer at
`INSERT-CONTACT-EMAIL`.

We'll acknowledge your report as soon as we can and keep you updated on the fix.
